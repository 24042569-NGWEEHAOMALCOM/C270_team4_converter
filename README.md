# Converter Web Application

## Project Overview

This project is a web-based unit converter application developed as part of a coursework assignment.  
The application allows users to perform basic unit conversions using a simple and intuitive interface.

### Version 1 Features
- Temperature conversion (Celsius ↔ Fahrenheit)
- Distance conversion (Kilometres ↔ Miles)
- Frontend implemented using HTML, CSS, and JavaScript
- No backend required (all logic runs client-side)

---

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Version Control:** Git & GitHub
- **CI/CD:** GitHub Actions
- **Containerisation:** Docker (Nginx)
- **Hosting (optional):** Vercel / Docker container
